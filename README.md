\# 🏏 Dhoni Review System (DRS)



A Python-based cricket Decision Review System simulation inspired by the review workflow used in cricket.



\## Features



\- Cricket video playback

\- Fast and slow video navigation

\- Previous and forward controls

\- Decision Pending screen

\- Sponsor/review transition

\- OUT / NOT OUT decision display

\- Interactive graphical interface



\## Technologies Used



\- Python

\- OpenCV

\- Tkinter

\- Pillow

\- imutils
